ANGULAR HANDS-ON 1 NOTES

1. angular.json
   - Angular workspace configuration.

2. package.json
   - Contains project dependencies and npm scripts.

3. src/
   - Contains the application source code.

4. app/
   - Contains Angular components.

5. app.ts
   - Root component of the application.

6. app.html
   - Root HTML template.

7. app.css
   - Global styles for the root component.

8. public/
   - Static assets like favicon.

9. ng serve
   - Runs the Angular development server.

10. ng build
    - Builds the project for production.
